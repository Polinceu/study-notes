# 算法：排序复杂度对照表，选排序先看数据规模

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
| ---- | ---- | ---- | ---- | ---- |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 否 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 是 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 否 |
| 插入排序 | O(n²) | O(n²) | O(1) | 是 |

## 怎么选

- 通用场景：快速排序，平均最快，标准库的 `sort` 基本都是它或它的变体
  （Python 的 Timsort 是归并+插入的混合，是稳定的）。
- 要求稳定（相等元素保持原顺序）：归并排序或 Timsort。
- 数据基本有序、规模小：插入排序反而快，近乎 O(n)。

## 两个常被问的点

- 快排最坏 O(n²) 出现在每次都选到最大/最小元素当基准，随机选基准或三数取中能避开。
- "稳定"只在排序键相同、还需要保留原有顺序时才重要，比如先按时间排、再按分数排。
